# 几猫3A大作 🐱🔫

> 使用 Fable5.2 自主研发的国产第一人称射击游戏 · 浏览器可玩 · 开发体验版

---

## 🎮 一句话介绍

纯前端构建的沉浸式 FPS —— **几猫港区防御系统失控，切断三处中继，突破封锁，登船撤离。**

## ✨ 项目亮点

- **单文件即开即玩**：全部游戏逻辑、渲染引擎、UI、着色器、音频打包在一个 `index.html` 中，双击或启一个静态服务器即可体验。
- **自研引擎 Fable5.2**：WebGL 渲染管线，包含 PBR 材质、阴影、后处理（Bloom、色调映射、SSAO 等）、体积光、焦散涂层瞄具、雨面法线扰动等次世代视觉效果。
- **完整 FPS 玩法闭环**：HUD（罗盘、血条、弹药、命中反馈、波次警告、伤害方向指示、世界空间目标标记）、武器系统（开火 / 瞄准 / 换弹 / 散布）、玩家机动（跳跃 / 冲刺 / 蹲伏 / 潜行）、近战。
- **AI 敌人系统**：两种机械敌人 —— **机械飞鸥**（悬停，发射能量螺栓）、**机械猎犬**（地面巡逻，冲锋近战）。具备 LOS 视线检测、巡逻 / 调查 / 交战状态机、token 机制控制同屏上限、枪声聚堆触发。
- **多端适配**：
  - PC：键鼠（WASD + 鼠标），支持鼠标锁定（Pointer Lock API）
  - 移动端：虚拟摇杆 + 屏幕按钮，自动切换 HUD 布局
  - 手柄：标准 Xbox/PS 手柄按键映射
- **波次生存机制**：多波次敌人递进，波间警告提示，通关后行动简报（用时 / 命中率 / 摧毁数 / 评级）。
- **无障碍友好**：`prefers-reduced-motion` 支持，屏幕阅读器可朗读任务目标、通讯字幕、面板标题等。

## 🏗️ 技术栈

| 层 | 技术 |
|----|------|
| 渲染 | WebGL + Three.js（内嵌到单文件） |
| 着色 | GLSL（PBR、雨面扰动、能量螺栓、瞄具涂层、体积光） |
| 物理 | 自研 AABB 碰撞检测 + 射线投射 + 视线检测 |
| 音频 | Web Audio API（合成音效） |
| 存储 | `localStorage` 持久化设置（画质 / 灵敏度 / 音量 / FOV） |
| 兼容 | 支持 Chrome / Edge / Safari（macOS、iOS、Android、Windows） |

## 🚀 本地运行

项目**没有依赖、没有构建步骤**，两种方式任选其一：

```bash
# 方式一：直接双击打开
open index.html

# 方式二：起一个本地静态服务器（推荐，确保音频 / 全屏权限正常）
cd jm && python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```
